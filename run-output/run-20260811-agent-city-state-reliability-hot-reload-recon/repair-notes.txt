Design notes:
  - Backup rotation: .bak = most recent committed state; .bak.1..bak.4 older;
    STATE_BACKUPS=5 total. Rotation is best-effort (never blocks the primary write).
  - Recovery semantics: backup holds the last fully-committed state (one save behind
    the primary); a mid-write crash therefore loses at most the interrupted write's
    delta, never committed data. No-backup corrupt file still starts empty (no crash).
  - Atomic write: identical JSON bytes to previous write_text (json.dump indent=2,
    utf-8) — happy-path behavior unchanged.
